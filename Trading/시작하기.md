# 주식 자동매매 봇 - 시작하기

전체 과정을 **순서대로** 안내합니다.

---

## Phase 1: API 키 발급 (실행 전 필수)

### 1단계: 한국투자증권 계좌

- **한국투자증권** 실계좌 또는 모의투자 계좌가 있어야 합니다.
- 없으면: [한국투자증권](https://www.koreainvestment.com)에서 계좌 개설

### 2단계: Open API 서비스 신청

1. **KIS Developers** 접속  
   → https://apiportal.koreainvestment.com

2. **회원가입** (한국투자증권 계좌로 연동)

3. **처음 시작하기** 또는 **서비스 신청** 메뉴 선택

4. **모의투자** 선택 후 신청
   - 실거래 전 테스트용
   - 별도 비용 없음

5. 신청 완료 후 **앱키(App Key)**, **앱시크릿(App Secret)** 발급
   - 포털 > 내 정보 또는 API 관리에서 확인
   - **복사해서 안전한 곳에 보관**

### 3단계: 모의투자 계좌 확인

- 한국투자증권 **앱** 또는 **홈페이지** 로그인
- **모의투자** 메뉴에서 모의투자 계좌 개설 (없는 경우)
- **계좌번호 앞 8자리** 확인 (예: 12345678)

### 4단계: HTS ID 확인

- KIS Developers 포털 로그인 시 사용하는 **ID** (이메일 또는 고객 ID)

## Phase 2: 키 설정 (config 파일)

### 1단계: 설정 파일 열기

**파일**: `config/kis_devlp.yaml`  
(메모장, VS Code 등으로 열기)

### 2단계: 아래 값만 수정

```yaml
# ★ 모의투자 (발급받은 값 입력) ★
paper_app: "PS로시작하는_앱키_붙여넣기"
paper_sec: "앱시크릿_붙여넣기"

# HTS ID (KIS Developers 로그인 ID)
my_htsid: "본인_로그인_ID"

# 모의투자 계좌번호 앞 8자리
my_paper_stock: "12345678"
my_paper_future: "12345678"
```

- `paper_app`, `paper_sec`: 발급받은 값 그대로 입력 (따옴표 유지)
- `my_htsid`: KIS Developers 로그인 ID
- `my_paper_stock`, `my_paper_future`: 모의투자 계좌 8자리 (같은 값 입력 가능)

### 3단계: 모의투자 모드 확인

**파일**: `config/settings.yaml`

```yaml
mode: "vps"   # vps = 모의투자 (이 값이어야 함)
```

## Phase 3: 서버(봇) 실행

### 1단계: 의존성 설치 (최초 1회)

```bash
pip install -r requirements.txt
```

또는

```bash
python -m pip install -r requirements.txt
```

### 2단계: 봇 실행

```bash
python main.py
```

또는 **run.bat** 더블클릭 (Windows)

### 3단계: 실행 시 동작 순서

1. **인증** → API 토큰 발급
2. **전략 검증** → 백테스트 자동 실행
3. **차트 생성** → `charts_output/` 에 저장
4. **매매 루프** → 장 시간(09:00~15:30) 동안 주기적 체크

### 4단계: 종료

- **Ctrl + C** 로 종료

## 전체 흐름 요약

```
[1] API 발급 (apiportal.koreainvestment.com)
    → paper_app, paper_sec 발급

[2] config/kis_devlp.yaml 수정
    → paper_app, paper_sec, my_htsid, my_paper_stock 입력

[3] config/settings.yaml 확인
    → mode: "vps" (모의투자)

[4] pip install -r requirements.txt

[5] python main.py
```

---

## 실행 환경 (서버처럼 동작)

- **PC에서 실행**: 장 시간(09:00~15:30) 동안 켜두면 자동 매매
- **24시간 서버**: VPS, AWS 등에 올려 두고 `python main.py` 를 백그라운드로 실행
- **Windows 서비스**: NSSM 등으로 등록하면 PC 재부팅 후에도 자동 실행

---

## 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 토큰 발급 실패 | paper_app, paper_sec 오타, 따옴표 확인 |
| 계좌 오류 | my_paper_stock 8자리 확인 |
| 데이터 없음 | 장 시간(09:00~15:30)인지 확인 |
| 모듈 없음 | `pip install -r requirements.txt` 재실행 |
