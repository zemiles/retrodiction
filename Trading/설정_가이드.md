# API 키 설정 가이드 (모의투자)

## 1. API 키 발급 받기

1. **한국투자증권 Open API** 포털 접속  
   → https://apiportal.koreainvestment.com

2. **회원가입 / 로그인**

3. **모의투자 API 신청**
   - 상단 메뉴: **서비스 신청** 또는 **처음 시작하기**
   - **모의투자** 선택 후 신청
   - 모의투자 전용 **앱키(App Key)** 와 **앱시크릿(App Secret)** 발급

4. **모의투자 계좌 개설**
   - 한국투자증권 앱 또는 홈페이지에서 **모의투자 계좌** 개설
   - 발급된 **모의투자 계좌번호** 확인 (앞 8자리)

5. **HTS ID 확인**
   - KIS Developers 포털 로그인 시 사용하는 **고객 ID** (이메일 또는 ID)

---

## 2. API 키 넣는 위치

**파일 경로**: `config/kis_devlp.yaml`

이 파일을 열어서 아래 항목만 **모의투자용**으로 수정하면 됩니다.

```yaml
# 모의투자 (여기만 입력하면 됩니다!)
paper_app: "발급받은_모의투자_앱키"
paper_sec: "발급받은_모의투자_앱시크릿"

# HTS ID (KIS Developers 로그인 ID)
my_htsid: "본인_HTS_ID"

# 모의투자 계좌번호 앞 8자리
my_paper_stock: "12345678"
my_paper_future: "12345678"
```

> ⚠️ **실전투자(my_app, my_sec)** 는 나중에 실거래할 때 입력하세요.  
> 지금은 모의투자만 사용하므로 **paper_app, paper_sec** 만 입력하면 됩니다.

---

## 3. 모의투자 모드 확인

**파일**: `config/settings.yaml`

```yaml
# vps = 모의투자, prod = 실전투자
mode: "vps"
```

`mode: "vps"` 이면 **모의투자**로 동작합니다. (기본값)

---

## 4. 전체 설정 예시

`config/kis_devlp.yaml` 예시:

```yaml
# 실전투자 (나중에 입력)
my_app: "앱키_입력"
my_sec: "앱시크릿_입력"

# 모의투자 ← 여기 입력!
paper_app: "PSxxxxxxxxxxxxxxxxxxxxxxxx"
paper_sec: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

my_htsid: "your_email@example.com"
my_acct_stock: "12345678"
my_acct_future: "12345678"
my_paper_stock: "87654321"   # 모의투자 계좌 8자리
my_paper_future: "87654321"

my_prod: "01"

# 아래는 수정하지 마세요
prod: "https://openapi.koreainvestment.com:9443"
ops: "ws://ops.koreainvestment.com:21000"
vps: "https://openapivts.koreainvestment.com:29443"
vops: "ws://ops.koreainvestment.com:31000"
my_agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/114.0.0.0 Safari/537.36"
```

---

## 5. 실행 순서

1. `config/kis_devlp.yaml` 에 모의투자 앱키·계좌 입력
2. `config/settings.yaml` 에서 `mode: "vps"` 확인
3. `pip install -r requirements.txt`
4. `python main.py` 실행

---

## 6. 주의사항
